# Basic Example

## Prompt
We want to build a new multi-agent app with a web UI.

## Expected Behavior
1. Require Streamlit for UI.
2. Require Microsoft Agent Framework for orchestration.
3. Require Microsoft Foundry Prompt agent or Hosted agent for individual agents.
4. Allow TypeScript only with explicit use-case justification.

## Example Response
Approved if implemented with Streamlit, Microsoft Agent Framework, and Foundry Prompt/Hosted agents. TypeScript is allowed only when justified by concrete integration needs.
